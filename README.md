# Островок - релизы

Здесь только готовые APK Островка: капсула в стиле Dynamic Island вокруг фронтальной камеры, Android 12 и новее. Исходников тут нет.

## Автообновление через Obtainium

1. Установи Obtainium: скачай APK из последнего релиза на https://github.com/ImranR98/Obtainium/releases (для большинства телефонов подходит вариант arm64-v8a).
2. В Obtainium нажми "Добавить приложение" (Add App), вставь ссылку `https://github.com/burstshadow19/ostrovok-releases` и подтверди.
3. Нажми "Установить" и разреши Obtainium устанавливать приложения.
4. Открой Островок и включи то, что он попросит: спецвозможности и доступ к уведомлениям.

Дальше Obtainium сам проверяет новые версии. Чтобы он ставил их без вопросов, включи в его настройках фоновые обновления.

Тихо обновлять Android разрешает, только если приложение изначально ставил сам Obtainium. Если Островок уже стоял, первое обновление спросит подтверждение, дальше пойдет само.

Если после обновления капсула пропала, проверь, что служба Островка в спецвозможностях все еще включена: некоторые прошивки ее выключают.
